# 杭电社团推荐与报名平台

## 一句话介绍
帮助杭电新生在开学季通过兴趣标签快速匹配并报名心仪社团。

## 为什么做
新生面对上百个社团时，信息分散在摊位、公众号和学长经验里，选择成本高，容易错过合适社团。

## 核心功能
- 选择 3–5 个兴趣标签（多选）
- 点击「生成推荐」，前端按预置社团数据库计算匹配度，输出 Top 3
- 每张卡片展示社团名称、一句话介绍、推荐理由和联系方式
- 未选标签时按钮禁用并给出提示；无匹配时说明原因，允许重新选择

## 使用方法
1. 打开页面，页面焦点在兴趣标签区
2. 点击你感兴趣的标签（可多选）
3. 点击「生成推荐」按钮
4. 查看推荐社团卡片，点「联系社团」获取联系方式
5. 如需重新推荐，更换标签后再次点击按钮

## 在线体验
- 公开链接：https://boisterous-genie-bc584d.netlify.app
- 示例输入：勾选「编程、技术、人工智能」三个标签，点击生成推荐

## 已知限制
- 数据为静态演示数据，不是杭电社团官网实时数据
- 「立即报名」按钮仅做提示，未接入真实报名表单
- 联系方式为示例内容，使用前需与官方渠道核实
- 推荐仅基于标签匹配，不涉及个性化算法或后端计算

## AI 使用说明
本项目为纯前端静态页面，未调用任何 AI 接口。页面行为可通过浏览器开发者工具和查看源代码核验。
