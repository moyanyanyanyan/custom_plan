# 像素道具系统

本文按当前代码说明道具锻造与收藏，不作为测试通过或线上部署的记录。

## 当前交互

- 图鉴包含卡牌与道具两个标签页。
- 每个本地自然日最多锻造一次道具。
- 用户可以选择已有发明卡牌作为素材；没有卡牌时也可以不投卡。
- 桌面端依次生成 AI 文案与像素图；界面显示读取素材和生成图片阶段。
- AI 文案不可用时使用本地道具池，图片不可用时显示文字占位。
- 浏览器端当前采用本地降级道具，不调用桌面 AI 命令。
- 道具按获得时间倒序展示，记录素材卡牌、附魔和是否降级。

## 生成与数据

业务入口是 `src/hooks/useItems.ts`，界面入口是
`src/components/ItemCollection.tsx` 与 `ItemForgeModal.tsx`。

`PixelItem` 包含名称、描述、任务来源、获得时间、本地日期键和附魔；
可选字段包括图片资源 ID、素材卡牌 ID/名称及降级标记。
锻造不会从收藏中消耗素材卡牌。

当前界面使用 gold 档位的附魔概率。附魔类型包括称号、升级、诅咒和特殊；
随机附魔在 AI 文案与本地降级两条路径中均适用。

## 存储与兼容

道具写入统一的 `AppData.items`，复用浏览器与桌面的数据仓储，
不另建一套独立存储。图片通过已有资产接口保存和读取。
旧数据缺少道具数组时使用空数组，加载时按现有校验规则过滤无效记录。

## 修改注意事项

- 增加字段时同步检查类型、默认值、校验和 Rust 数据模型。
- 本地日期限制与获得时间承担不同职责，不用 UTC 日期替换每日限制键。
- 新锻造入口复用现有进行中保护和当日限制。
- 验证结果应来自实际执行，不沿用历史分支的测试状态。
