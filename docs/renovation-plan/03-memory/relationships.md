# 长期关系与相处变化

[记忆目录](README.md)

## 已确认

关系会随聊天和经历变化，角色按自己的性格与底线相处。允许复杂感受，不将所有角色变成同一种温柔陪伴者。长期缺席逐渐生疏，但不因缺席自动怨恨。

## 建议状态

| 维度 | 含义 |
|---|---|
| 信任 | 相信用户表达与承诺 |
| 亲近 | 愿意靠近与披露自身感受 |
| 尊重 | 认可对方、感到边界被认真对待 |
| 安全感 | 能安心表达不同意见 |
| 熟悉感 | 交流是否自然、是否需要重新接近 |
| 未解决事项 | 尚未解释或修复的具体问题 |

内部数值与文字原因结合，不能一个好感值决定全部关系。初始陌生、伙伴、熟人等需要角色创建时明确，用户身份不自动使其成为特殊例外。

## 更新建议

- 承诺兑现、边界被尊重、可信解释、反复失约与持续修复是有效依据。
- 单次普通事件小幅影响，重大或反复事件需要充分来源。
- 一次不悦不让所有关系维度一起下降；亲近和信任可以不同方向。
- 道歉可缓和即时情绪；长期信任是否恢复，要看解释、事件和后续行为。
- 不同意见、拒绝建议、不回复不自动判定为冒犯。
- 允许表达界限，不通过羞辱、威胁离开或负罪感要求用户互动。
- 每个事件只计算一次，重试和重复回忆不重复累积影响。

## 缺席

建议短期情绪随时间平复，只让熟悉感缓慢下降，不自动扣信任、尊重或亲近。回归后通过有实质内容的相处回暖，不按消息条数刷数值。

此前 14 天起降、每周 2／100、最多 20、每日恢复上限等只是参数示例，尚未确认。

## 验收

能表现“仍亲近但对承诺存疑”；一次误解澄清后重新评估；长期缺席不自动怨恨；不因某句自生成亲密台词跳跃升级关系。
