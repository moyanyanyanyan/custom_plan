# 非核心性格、世界认识与用户认知

[记忆目录](README.md)

## 已确认

- 核心人设和核心世界规则不能被聊天改变。
- 非核心性格与世界认识允许长期、显著成长，不限于小幅风格调整。
- 对用户的认知不按时间直接删除，但可被新信息纠正，过时内容不能一直作为当前事实。
- 经历自然遗忘不自动恢复性格或清空认知。

## 建议更新机制

| 对象 | 条件 | 需要避免 |
|---|---|---|
| 性格成长 | 多个独立经历支持同方向，不违背核心，有可解释过程 | 用户反复命令改变性格就立即照做 |
| 世界认识 | 有来源，区分核心规则、可塑观点和假设 | 将随口虚构当作世界事实 |
| 用户明确资料 | 用户明确说明或纠正，语境不是引用和举例 | 从画面或 AI 台词推断现实事实 |
| 用户行为判断 | 多次相关行为支持，记录情境与确定程度 | 一句冒犯就永久贴负面标签 |

性格变化先进入候选，积累支持与反例，再决定是否成为当前状态。重要事件可以成为转折候选，但需要后续解释与行为支持，不自动发生人格反转。

更新保存原状态、当前状态、来源、变化原因、确定程度、版本。事实纠正与成长不同：用户澄清“刚才只是例子”应及时修正误解，不必等多次证据。

冷静、对外人疏离的角色可以逐步把用户纳入信任范围，也可以在非核心部分产生明显变化；不能把所有角色统一成长为外向温柔的角色。

## 建议参数，未确认

曾建议“至少 3 个独立轮次、跨 2 段会话”作为观察门槛，仅为讨论示例，不应实现为达到次数必定改变。最终需要结合证据质量、反例和角色塑性。

## 待定

- M-03：变化触发门槛、重大转折处理、反例权重、核心与可塑矛盾的呈现。
- 用户在设置修改核心后，如何处理冲突的现有成长状态，不能静默清空经历。
- 明确认知与角色推测的存储粒度、失效判定与查看文案。
- 是否允许 UI 人工纠正入口尚未确定；聊天中的解释可以成为新证据，不授予直接改数据库能力。

## 验收

夸奖、辱骂或重复要求不会直接改写核心；错误推断可被澄清；依据淡化后不编造证据；新的反例能够更新认知而非永远坚持旧判断。
