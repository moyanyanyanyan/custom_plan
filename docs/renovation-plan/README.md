## 七个模块

| 模块 | 负责什么 | 不负责什么 |
|---|---|---|
| [01 平台适配与权限](01-platform/README.md) | Windows、安卓、悬浮窗、生命周期、屏幕采集与权限 | 跨设备数据合并、模型理解 |
| [02 UI 与交互](02-ui/README.md) | 主面板、角色选择、设置、聊天和记忆查看 | 决定角色状态如何变化 |
| [03 记忆与角色状态](03-memory/README.md) | 记忆提炼检索、认知、成长、情绪、关系、遗忘 | 模型供应商、通用文档解析 |
| [04 聊天与模型](04-chat-models/README.md) | 会话、流式回复、多模态、上下文、主动聊天 | 数据同步协议 |
| [05 数据与同步](05-data-sync/README.md) | SQLite、PostgreSQL、迁移、离线队列、冲突、资源同步 | 容器安装与网络入口 |
| [06 后端部署与通信](06-server/README.md) | 电脑托管、Docker、局域网连接、配对、服务运维 | 业务记录合并规则 |
| [07 知识库与文件](07-knowledge/README.md) | 人设资料、世界观详情、文件解析、切片与检索 | 交流经历与情绪更新 |

“平台适配”和“服务器通信”分别管系统能力与网络服务；原本混在其中的存储同步独立成模块。聊天模型与文件知识库也独立，避免记忆模块承担全部 AI 工作。

## 文档状态规则

- **已确认**：用户明确选择的产品行为；讨论修改时先更新对应正文。
- **建议方案**：助手提出的实现方向，尚不等于用户批准了具体技术选型。
- **建议参数**：天数、阈值、模型名称、并发数、token 预算等，实施前需要校准。
- **待定**：存在关键歧义或尚未讨论，必须保留问题，不能自行写成要求。
- **当前事实**：从代码或环境观察到的现状，不表示目标功能已实现。

每条规则在所属模块只维护一份，其他文件用链接引用。已被用户取消的要求不写入兼容逻辑或未来 TODO。图片是参考快照；如与最新决策冲突，以最新文字规则为准。

后续每次讨论结束：更新模块正文 → 更新决策或待定索引 → 简述修改位置。接口和数据库结构在讨论成熟后再细化，不提前生成无调用方的完整实现规范。
