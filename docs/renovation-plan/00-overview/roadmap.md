# 阶段与验收草案

全部阶段仍未开工。顺序是建议，未确定问题需要在对应阶段开始前补齐。

| 阶段 | 内容 | 结束条件 |
|---|---|---|
| 0 设计固化 | 持续完善本目录、核对模块接口 | 当前阶段关键问题有明确结论，不以文档数量判断完成 |
| 1 安卓可行性 | 普通面板、本地保存、悬浮头像与展开、输入法 | 小米平板真机可增删改任务并重启保留；Windows 不退化 |
| 2 数据与局域网 | SQLite、Docker PostgreSQL、API、迁移、资源与离线同步 | 两端断网操作、重连和冲突选择可验证；旧数据可恢复 |
| 3 UI 与聊天 | 角色选择、设置分区、聊天、图片输入、个人计划连接 | 不串角色、草稿不丢、任务与收藏归属正确 |
| 4 记忆与角色 | Claude-Mem、每轮提炼、角色状态、情绪关系、自然遗忘 | 核心不被聊天改写、事件不重复应用、记忆隔离 |
| 5 资料与陪伴 | 知识库、屏幕采集、主动聊天、耗电费用优化 | 授权和停止有效，真机采样与主动消息体验通过 |

## 跨模块验收重点

- 平台：权限拒绝仍能操作普通计划；系统结束采集后正确清理状态。
- UI：切换角色只改变角色范围内容，不改变个人计划与收藏。
- 数据：重试幂等，删除任务不会因另一端离线重连复活。
- 角色：事实、推测、角色扮演与核心设定有清晰边界。
- 情绪：误解可以修正；后台重试不会重复增加情绪或改变关系。
- 记忆：每轮检查不等于每轮新增，已自然遗忘的经历不会被后台恢复。
- 部署：重建容器仍保留数据，备份恢复经过实际演练。

性能指标与测试样本数量暂作为待定验收参数，不沿用先前建议数字作为已承诺性能。
