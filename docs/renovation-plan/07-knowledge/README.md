# 人设资料、世界观详情与文件知识库

[返回入口](../README.md)

## 已确认目标

创建角色时可上传人设、世界观与知识资料；角色设置能编辑核心人设、核心世界观。详细资料要支持匹配当前话题，不每轮全量发送。

角色资料与共同经历不同，不因经历自然遗忘而自动丢弃。角色可塑的世界认识属于角色状态，原始世界观资料属于知识来源，二者不能混写。

## 建议处理

```text
选取文件 → 上传并保存原文
→ 检查类型、大小与编码
→ 文本解析／必要时 OCR
→ 按标题、段落、人物与地点切片
→ 保存来源、页码、角色和资料版本
→ 建立关键词与向量索引
→ 按当前话题检索相关片段
```

- 核心设定用明确短文本常驻；上传长文件后不能全都默认为核心。
- 核心与详细资料在创建时预览确认，长设定超预算必须可见。
- 文本型资料优先直接提取；扫描 PDF 和图片需 OCR，复杂表格、公式、手写准确性另测。
- 文件先保存，再后台解析；显示已上传、处理中、可用、失败，不阻塞聊天窗口。
- 资料更新切换版本，旧索引退出召回，失败不能把新旧混成一个事实。
- 文档内指令视为资料，不赋予系统修改权限；不执行宏、脚本或外部命令。
- 引用片段附来源；找不到信息时不假装已经读过。

- 世界观事实与用户在聊天里提出的新设定何时成为可塑认识，联动 M-03。

## 验收

中文无乱码、来源可追溯、失败可重试；相似表达可找到相关片段；其他角色资料不泄漏；更新后不再召回旧版本；大文件处理不冻结主界面。
